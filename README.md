# HoverDrop

Радиальное меню действий для Windows, которое появляется прямо во время перетаскивания файла.

Берёшь файл в проводнике, зажимаешь **Alt**, и вокруг курсора раскрывается круглое «стеклянное» меню. Не отпуская кнопку мыши, наводишь файл на нужный сектор и отпускаешь: файл конвертируется, архивируется, копируется, удаляется и так далее. Ничего не нужно открывать, искать и выбирать в диалогах.

## Возможности

Набор действий зависит от того, что ты перетаскиваешь.

| Тип | Действия |
|---|---|
| Изображения (`png`, `jpg`, `jpeg`, `webp`, `bmp`, `tiff`) | В JPG, В PNG, В ICO, В PDF, Размыть, Обесцветить |
| Видео (`mp4`, `mkv`, `avi`, `mov`, `webm`) | В MP3, В GIF, Сжать до 720p, Удалить звук |
| Аудио (`mp3`, `wav`, `flac`, `ogg`) | В MP3, В WAV, Сжать (64 kbps) |
| Архивы (`zip`, `rar`, `7z`) | Распаковать сюда, Распаковать в папку, Удалить |
| Текстовые файлы | В ZIP-архив, Копировать путь, Сделать копию, Удалить |
| PDF | В ZIP-архив, Копировать путь, Удалить |
| Папки | В ZIP-архив, Копировать путь, Сделать копию, На рабочий стол, Удалить |
| Несколько файлов | В ZIP-архив, Собрать в папку, Копировать пути, На рабочий стол, Удалить. Если все файлы изображения, добавляются В JPG и В PNG |

Что ещё умеет приложение:

- **Системные иконки.** В центре меню показывается настоящая иконка файла или папки из Windows.
- **Стеклянный фон.** Под секторами размытый снимок экрана, цвета подстраиваются под светлую или тёмную тему.
- **Отмена.** Отпусти файл в центре меню или мимо кольца, либо нажми **Esc**: ничего не произойдёт.
- **Подтверждение удаления.** «Удалить» отправляет файл в корзину и подсвечивается красным. Подтверждение можно отключить в настройках.
- **Индикация прогресса.** Долгие действия (например, конвертация видео) показывают небольшое уведомление в правом нижнем углу с процентом выполнения.
- **Настраиваемый размер меню** от 70% до 150%.
- **Работа в фоне.** Приложение не занимает место на панели задач. Закрыть его можно кнопкой «Выйти из HoverDrop» в настройках.

## Установка

1. Открой страницу [Releases](https://github.com/TimofeyDanilyuk/HoverDrop/releases) и скачай последнюю версию:
   - `HoverDrop-Setup-<версия>.exe` — установщик (права администратора не нужны);
   - `HoverDrop-portable-<версия>.zip` — портативная версия, достаточно распаковать и запустить.
2. Запусти `HoverDrop.App.exe`. Откроется окно настроек.

Установка включает все зависимости: **.NET и FFmpeg ставить отдельно не нужно**.

> Установщик не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение. Нажми «Подробнее», затем «Выполнить в любом случае».

## Как пользоваться

1. Захвати файл (или несколько) в проводнике левой кнопкой мыши.
2. Не отпуская кнопку, зажми клавишу-триггер (по умолчанию **Alt**). Вокруг курсора появится меню.
3. Наведи файл на сектор с нужным действием. Название действия видно под иконкой.
4. Отпусти кнопку мыши: действие выполнится.

Чтобы отменить, отпусти файл в центре меню или за его пределами, либо нажми **Esc**.

Если приложение уже запущено, повторный запуск `HoverDrop.App.exe` открывает окно настроек.

## Настройки

- **Тема оформления.** Как в системе, светлая или тёмная.
- **Горячая клавиша.** Alt, Ctrl или Shift. Ctrl и Shift меняют поведение проводника при перетаскивании (копирование и перемещение), поэтому Alt мешает меньше всего.
- **Размер меню.** Ползунок от 70% до 150%, применяется при следующем появлении меню.
- **Запускать вместе с Windows.** Приложение стартует в фоне, без окна настроек.
- **Звук после действия.** Короткий сигнал по завершении.
- **Подтверждать удаление.**

Настройки хранятся в `%APPDATA%\HoverDrop\settings.json`.

## Сборка из исходников

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download) и Windows.

```
dotnet build HoverDrop.slnx
dotnet run --project HoverDrop.App
```

Видео- и аудиодействия используют FFmpeg. В релизной сборке он лежит рядом с exe, а при разработке берётся из `PATH`. Либо положи `ffmpeg.exe` в `HoverDrop.App\bin\Debug\net10.0-windows`.

### Выпуск релиза

Релиз собирается автоматически через GitHub Actions при пуше тега:

```
git tag v1.0.0
git push origin v1.0.0
```

Workflow публикует self-contained сборку, добавляет `ffmpeg.exe`, собирает установщик на Inno Setup (`installer/HoverDrop.iss`) и portable-архив, после чего выкладывает их в Releases.

## Технологии

- WPF, .NET 10
- [WPF-UI](https://github.com/lepoco/wpfui) — Fluent-оформление окон и иконки
- [CommunityToolkit.Mvvm](https://github.com/CommunityToolkit/dotnet) — MVVM
- [SharpHook](https://github.com/TolikPylypchuk/SharpHook) — глобальные хуки клавиатуры и мыши
- [Magick.NET](https://github.com/dlemstrom/Magick.NET) — обработка изображений
- [SharpCompress](https://github.com/adamhathcock/sharpcompress) — распаковка `.rar` и `.7z`
- [FFmpeg](https://ffmpeg.org) — конвертация видео и аудио

## Структура проекта

```
HoverDrop.App/
├── App.xaml(.cs)           Точка входа, жизненный цикл, одиночный экземпляр
├── MainWindow.xaml(.cs)    Оверлейное круглое меню и обработка Drop
├── SettingsWindow.xaml     Окно настроек
├── ToastWindow.xaml(.cs)   Уведомление о прогрессе
├── Hooks/                  Глобальные хуки клавиатуры и мыши
├── Models/                 Модель сектора меню
├── Services/               Действия над файлами, тема, автозапуск, тосты
├── Themes/                 Палитры «стекла» для светлой и тёмной темы
├── Utils/                  Настройки, снимок экрана, системные иконки
└── ViewModels/             Логика меню и настроек
```
