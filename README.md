# HoverDrop

Радиальное меню действий для Windows, которое появляется прямо во время перетаскивания файла.

Берёшь файл в проводнике, зажимаешь **Alt**, и вокруг курсора раскрывается круглое «стеклянное» меню. Не отпуская кнопку мыши, наводишь файл на нужный сектор и отпускаешь: файл конвертируется, архивируется, копируется, удаляется и так далее. Ничего не нужно открывать, искать и выбирать в диалогах.

---

## Возможности

Набор действий адаптируется под тип перетаскиваемого файла:

| Тип | Доступные действия |
|---|---|
| **Изображения** (`png`, `jpg`, `jpeg`, `webp`, `bmp`, `tiff`) | В JPG, В PNG, В ICO, В PDF, Размыть, Обесцветить |
| **Видео** (`mp4`, `mkv`, `avi`, `mov`, `webm`) | В MP3 (Аудио), В GIF, Сжать (720p), Удалить звук |
| **Аудио** (`mp3`, `wav`, `flac`, `ogg`) | В MP3, В WAV, Сжать (64kbps) |
| **Архивы** (`zip`, `rar`, `7z`) | Распаковать сюда, Распаковать в папку, Удалить |
| **Текстовые файлы и код** (`txt`, `md`, `json`, `cs` и др.) | В ZIP-архив, Копировать путь, Сделать копию, Удалить |
| **PDF** | В ZIP-архив, Копировать путь, Удалить |
| **Папки** | В ZIP-архив, Копировать путь, Сделать копию, На рабочий стол, Удалить |
| **Несколько файлов** | В ZIP-архив, Собрать в папку, Копировать пути, На рабочий стол, Удалить. *(Если все файлы — картинки, добавляются пакетная конвертация В JPG и В PNG)* |

### Что ещё умеет HoverDrop:

- ⏱️ **Каскадная анимация веера:** секторы кольца эффектно разворачиваются один за другим по часовой стрелке при появлении и стремительно схлопываются против часовой стрелки при закрытии.
- ✨ **Плавный Hover и фокус:** при наведении сектор плавно приподнимается над соседями и подсвечивается, а в центре кольца крупно отображается выбранное действие.
- 🌐 **Двуязычный интерфейс (RU / EN):** полная поддержка русского и английского языков (автоматически подстраивается под язык Windows либо выбирается вручную в настройках).
- 🪟 **Стеклянный фон (Glass / Blur):** под секторами создаётся мягкий размытый снимок экрана, автоматически подстраивающийся под светлую или тёмную тему оформления.
- 🔔 **Значок в системном трее:** быстрый доступ к настройкам, возможность временно приостановить работу приложения и проверить обновления.
- 🚀 **Автоматические обновления (Velopack):** приложение самостоятельно проверяет и скачивает новые версии в фоне, предлагая обновиться в один клик.
- 🛡️ **Безопасное удаление:** действие «Удалить» отправляет файлы в корзину и подсвечивается предупреждающим цветом. Запрос подтверждения можно включить или выключить в настройках.
- 📊 **Индикация прогресса (Toast):** для длительных фоновых задач (например, перекодирование видео или распаковка тяжелых архивов) в углу экрана отображается аккуратное уведомление со шкалой прогресса.
- 📏 **Масштабирование:** размер кольца настраивается от 70% до 150%.
- 🎯 **Отмена в любой момент:** отпусти файл в центре меню, мимо кольца или нажми **Esc** — действие отменится.

## Установка

1. Открой страницу [Releases](https://github.com/TimofeyDanilyuk/HoverDrop/releases) и скачай установщик `HoverDrop-Setup.exe`.
2. Запусти установщик (права администратора не требуются).
3. Приложение установится и сразу запустится со значком в трее и окном настроек.

> Все зависимости включены: **.NET и FFmpeg ставить отдельно не нужно**.
> Так как приложение распространяется как open-source проект без платной цифровой подписи, Windows SmartScreen может показать предупреждение при первом запуске. Нажми *«Подробнее»* $\to$ *«Выполнить в любом случае»*.

---

## Как пользоваться

1. Выдели файл (или группу файлов) в Проводнике или на Рабочем столе и начни перетаскивание левой кнопкой мыши.
2. Не отпуская кнопку, зажми клавишу-триггер (по умолчанию **Alt**). Вокруг курсора веером раскроется меню.
3. Наведи курсор на нужный сектор (название действия отобразится в центре).
4. Отпусти левую кнопку мыши — действие сразу выполнится.

Если нужно отменить операцию — просто отпусти файл в центре кольца, уведи курсор за его пределы или нажми **Esc**.

## Настройки

Окно настроек можно открыть из контекстного меню значка в системном трее или повторным запуском `HoverDrop.App.exe`:

* **Язык интерфейса:** Auto (как в системе), Русский или English.
* **Тема оформления:** Как в системе, Светлая или Тёмная.
* **Горячая клавиша:** Alt, Ctrl или Shift (рекомендуется Alt, так как Ctrl и Shift могут менять режим drag-and-drop в Проводнике).
* **Размер меню:** ползунок от 70% до 150%.
* **Запускать вместе с Windows:** автозапуск в фоновом режиме в трей.
* **Звуковой сигнал:** звуковое подтверждение успешного выполнения действия.
* **Подтверждать удаление:** диалог подтверждения перед перемещением в корзину.
* **Обновления:** проверка актуальной версии и автоматическая фоновая загрузка обновлений.

Настройки сохраняются в `%APPDATA%\HoverDrop\settings.json`.

## Сборка из исходников

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download) и Windows 10/11.

```bash
git clone https://github.com/TimofeyDanilyuk/HoverDrop.git
cd HoverDrop
dotnet build HoverDrop.slnx
dotnet run --project HoverDrop.App
```

### Выпуск нового релиза

Релиз собирается и публикуется автоматически через GitHub Actions при пуше тега версии:

```bash
git tag v1.2.0
git push origin v1.2.0
```

Workflow GitHub Actions:
1. Собирает оптимизированный self-contained билд под `win-x64`.
2. Встраивает FFmpeg.
3. Упаковывает релиз через [Velopack](https://velopack.io) с генерацией дельта-обновлений.
4. Публикует готовый установщик в GitHub Releases.

## Технологии

- **C# / WPF (.NET 10)**
- **[WPF-UI](https://github.com/lepoco/wpfui)** — современный Fluent Design (Mica, темы, иконки)
- **[CommunityToolkit.Mvvm](https://github.com/CommunityToolkit/dotnet)** — реактивная архитектура MVVM
- **[SharpHook](https://github.com/TolikPylypchuk/SharpHook)** — глобальный перехват ввода мыши и клавиатуры
- **[Velopack](https://velopack.io)** — автоматические обновления и инсталлятор
- **[Magick.NET](https://github.com/dlemstrom/Magick.NET)** — обработка и конвертация графики (ImageMagick)
- **[SharpCompress](https://github.com/adamhathcock/sharpcompress)** — работа с архивами `.zip`, `.rar`, `.7z`
- **[FFmpeg](https://ffmpeg.org)** — конвертация и оптимизация видео/аудио (лицензия GPL)
